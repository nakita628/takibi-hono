# Define Handler, split

An API generated by takibi-hono with `defineHandler: true` and `split: true` (see [`takibi-hono.config.ts`](./takibi-hono.config.ts)): one [`defineHandler`](https://hono.dev/docs/helpers/factory#definehandler) per operation, grouped by first path segment, with a client per group.

## What `defineHandler` changes

Each handler file in [`src/handlers`](./src/handlers) exports one `defineHandler` per operation, named by its method and path (`postUsersHandler`), and the group's Hono registering them (`usersHandler`). The options validate the request targets the operation declares and, under `response`, the JSON of its success response, so the value a handler returns is validated too. Compare [`split-api`](../split-api), which generates the same document as hono-openapi's `describeRoute` and validator middleware.

The handler bodies and the data in [`src/store.ts`](./src/store.ts) are written by hand; regenerating keeps them and writes the options again from the spec. A handler returns the value: the status is set with `c.status(201)`, and a miss is thrown as an `HTTPException` with the response to send.

## What `split` changes

- The app entry, [`src/index.ts`](./src/index.ts), exports each group under its name (`health`, `posts`, `users`). Every group is still registered on the one app.
- The client, [`src/client.ts`](./src/client.ts), is one client per group, typed by the routes of its group alone. A route's response type is what its `response` schema parses to ([`src/groups.ts`](./src/groups.ts)).
- rpc, [`src/rpc.ts`](./src/rpc.ts), calls the client of each operation's group.

## Try it

```bash
pnpm generate  # regenerate from openapi.yaml, keeping the handler bodies
pnpm dev       # serve the app at http://localhost:5173/api
pnpm check     # type-check, including src/groups.ts
pnpm test      # call rpc through every group's client
```

```bash
curl http://localhost:5173/api/health
curl http://localhost:5173/api/users/1
```

The one-file counterpart, generated without a config file, is [`define-handler-file`](../define-handler-file).
