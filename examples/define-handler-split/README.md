# Define Handler, split

An API generated by takibi-hono with `defineHandler: true` and `split: true` (see [`takibi-hono.config.ts`](./takibi-hono.config.ts)): a [`defineHandler`](https://hono.dev/docs/helpers/factory#definehandler) definition per operation, handler files calling them, grouped by first path segment, with a client per group.

## What `defineHandler` changes

[`src/routes.ts`](./src/routes.ts) defines every operation, `export const postUsersHandler = defineHandler({ json, response })`, named by its method and path as hono-takibi names a route. The options validate the request targets the operation declares and, under `response`, the JSON of its success response, so the value a handler returns is validated too. Nothing in it is yours; `pnpm generate` writes it over.

Each handler file in [`src/handlers`](./src/handlers) imports its definitions and calls each with the handler, `getUsersHandler(async (c, { query }) => ...)`, on the group's Hono (`usersHandler`). The handlers and the data in [`src/store.ts`](./src/store.ts) are written by hand; regenerating keeps a call you gave a handler, or middleware before it, and writes the stubs again for the rest. A handler returns the value: the status is set with `c.status(201)`, and a miss is thrown as an `HTTPException` with the response to send. Compare [`split-api`](../split-api), which generates the same document as hono-openapi's `describeRoute` and validator middleware.

## What `split` changes

- The app entry, [`src/index.ts`](./src/index.ts), exports each group under its name (`health`, `posts`, `users`). Every group is still registered on the one app.
- The client, [`src/client.ts`](./src/client.ts), is one client per group, typed by the routes of its group alone. A route's response type is what its `response` schema parses to ([`src/groups.ts`](./src/groups.ts)).
- rpc, [`src/rpc.ts`](./src/rpc.ts), calls the client of each operation's group.

## Try it

```bash
pnpm generate  # regenerate from openapi.yaml, keeping the handler bodies
pnpm dev       # serve the app at http://localhost:5173/api
pnpm check     # type-check, including src/groups.ts
pnpm test      # call rpc through every group's client
```

```bash
curl http://localhost:5173/api/health
curl http://localhost:5173/api/users/1
```

The same definitions without a config file, and an app written by hand against them, is [`define-handler-file`](../define-handler-file).
