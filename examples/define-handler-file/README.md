# Define Handler, one file

An API generated by takibi-hono's one-shot mode, `takibi-hono openapi.yaml -o src/api.ts`: no config file, one generated file.

## What the one-shot mode writes

[`src/api.ts`](./src/api.ts) holds everything the generator takes from [`openapi.yaml`](./openapi.yaml):

- The `components.schemas`, as zod schemas with their types (`UserSchema`, `User`).
- `api`, a Hono with every operation registered, each as a [`defineHandler`](https://hono.dev/docs/helpers/factory#definehandler) written inline in its route call, as Hono's own example writes it. The options validate the request targets the operation declares (`param`, `query`, `json`) and, under `response`, the JSON of its success response; the handler gets the validated values as its second argument and returns the value.

Nothing is split into files here, so nothing is named: compare [`define-handler-split`](../define-handler-split), whose handler files declare each operation's handler by name (`postUsersHandler`), as hono-takibi's `-o` writes route definitions for its template.

The handler bodies in `src/api.ts` are written by hand, with the data in [`src/store.ts`](./src/store.ts); regenerating keeps them, the middleware you put before one included, and writes the options again from the spec. The app, [`src/index.ts`](./src/index.ts), mounts `api` under `/api` and adds what is the app's own: the not-found handler here, middleware if you like.

A handler under a `response` schema returns the value, not `c.json()`: the status is set with `c.status(201)`, and a miss is thrown as an `HTTPException` with the response to send (`getUsersUserIdHandler`).

## Try it

```bash
pnpm generate  # regenerate src/api.ts from openapi.yaml, keeping the handler bodies
pnpm dev       # serve the app at http://localhost:5173/api
pnpm check     # type-check
pnpm test      # request every operation through the app
```

```bash
curl http://localhost:5173/api/health
curl http://localhost:5173/api/users/1
curl http://localhost:5173/api/users/0   # 400 from defineHandler, with the issues
```

The split counterpart, with a config file and a client per group, is [`define-handler-split`](../define-handler-split).
